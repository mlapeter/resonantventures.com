# resonantventures.com

Static landing page for Resonant Ventures, served by GitHub Pages.

- `index.html` is the whole site (the logo is drawn and animated in the page's script).
- `og.png`, `favicon.png` and `apple-touch-icon.png` are rendered from the page.
- Design history and mockups live in Mike's `general` repo under `projects/resonant-ventures/`.
